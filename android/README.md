# Android app source snapshot

This directory contains a clean-history copy of the HardwareShopPOS Android source, Gradle project files, schemas, tests, technical documents, and the owner-approved catalog assets. The original POS Git history is intentionally not included.

The owner approved publishing catalog purchase prices and stock quantities in this public repository. The website itself exposes only its separate approved name/size/unit/selling-price projection. Local Firebase configuration, signing credentials, databases, logs, and build outputs are excluded. This source snapshot is not a signed or production-connected app release.
