# Android app source snapshot

This directory contains a clean-history copy of the HardwareShopPOS Android source, Gradle project files, schemas, tests, and technical documents. The original POS Git history is intentionally not included.

Private shop catalog assets that contain purchase prices or stock, local Firebase configuration, signing credentials, local databases, logs, and build outputs are excluded. To build or run the POS, restore those owner-held files locally through the existing secure setup. This public snapshot is source access, not a ready-to-install or production-connected app.
