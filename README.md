# HardwareShopPOS source repository

This repository contains the customer catalog website source, Android POS source snapshot, technical project documents, and the catalog-only QR artwork.

- Public catalog website: https://hardwareshoppos.pages.dev/
- Online ordering: disabled; this deployment displays item names, sizes/units, and selling prices only.
- QR artwork: `release/qr/HardwareShopPOS-QR.png` and `.pdf`; captioned “SCAN TO VIEW ITEMS & PRICES”.
- Android source: `android/`; original POS Git history is not included.

Private shop purchase-price and stock catalog assets, live databases/backups, Firebase configuration, signing keys, local build outputs, deployment approvals, and credentials are excluded. Restoring owner-held local configuration is required to build a working shop installation. This public repository is not a production app release.
